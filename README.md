# AI Horizon

AI Horizon is a small static site that forecasts upcoming AI milestones and showcases experimental AI Labs.

Features
- Futuristic landing page with dynamic predictions
- AI Labs overview page for experiments and prototypes
- Small static JS to generate sample predictions (client-side)

Files
- index.html — Landing page (predictions + hero)
- labs.html — Labs overview
- styles.css — Visual theme and layout
- scripts/main.js — Small interactive behaviors

Run locally
1. Serve files from a static server (e.g., `npx http-server` or `python -m http.server`)
2. Open http://localhost:8080 (or the port your server uses)

Deployment
- Deploy as a static site on Netlify, Vercel, GitHub Pages, or any static hosting provider.
